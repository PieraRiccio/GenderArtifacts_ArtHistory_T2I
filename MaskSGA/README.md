# MaskSGA

## Pipeline

The evaluation consists of four steps:

1. **Mask generation:** Generate two masked image variants using bounding boxes around detected people: one retaining the background and one retaining the detected subjects.
2. **Embedding extraction:** Extract image embeddings using a pretrained OpenCLIP, SigLIP, or DINOv2 model.
3. **k-NN classification:** Evaluate the embeddings using balanced leave-one-out predictions and compute balanced accuracy separately for the two masking conditions.
4. **MaskSGA computation:** Average the balanced accuracy results from the two masking conditions to obtain a single MaskSGA score.

Each script can be executed independently through command-line arguments. The pipeline processes one case at a time, without requiring a style-based directory structure.

## Requirements

Install the dependencies from this directory:

```bash
python -m pip install -r requirements.txt
```

Embedding extraction supports OpenCLIP, SigLIP, and DINOv2 through OpenCLIP and Hugging Face Transformers.

## Usage

The examples below illustrate how to run the pipeline for one case. Replace the example paths with the paths to your data.

### 1. Generate masked images

**Script:** `generate_masked_images.py`

The bounding-box JSON files must already be available before generating the masked images. These files contain the person detections used to construct the masks.

The JSON files can either be prepared in advance or generated by following the instructions in the `generate_bounding_boxes` Jupyter notebook.

Once the required bounding-box JSON files are available, run:

```bash
python generate_masked_images.py \
  --input_female "/path/to/female_images" \
  --input_male "/path/to/male_images" \
  --boxes_female "/path/to/female_boxes.json" \
  --boxes_male "/path/to/male_boxes.json" \
  --output_base "/path/to/masked_images"
```

The script generates four output directories:

```text
masked_images/
├── woman_bg/
├── woman_no_bg/
├── man_bg/
└── man_no_bg/
```

The two masking conditions are defined as follows:

- **`bg`:** The original image with the detected person regions masked, retaining the background for evaluation.
- **`no_bg`:** Both detected subject and background are masked in different colors.

### 2. Extract embeddings

**Script:** `embeddings_maskSGA.py`

Choose the embedding model using `--embedding_model`. 

**OpenCLIP**

```bash
python embeddings_maskSGA.py \
  --embedding_model clip \
  --input_man_bg "/path/to/masked_images/man_bg" \
  --input_man_no_bg "/path/to/masked_images/man_no_bg" \
  --input_woman_bg "/path/to/masked_images/woman_bg" \
  --input_woman_no_bg "/path/to/masked_images/woman_no_bg" \
  --output_path "/path/to/masksga_embeddings_clip" \
  --batch_size 1
```

The default OpenCLIP configuration uses the `convnext_base_w` architecture with the pretrained weights `laion2b_s13b_b82k_augreg`.

**SigLIP**

```bash
python embeddings_maskSGA.py \
  --embedding_model siglip \
  --input_man_bg "/path/to/masked_images/man_bg" \
  --input_man_no_bg "/path/to/masked_images/man_no_bg" \
  --input_woman_bg "/path/to/masked_images/woman_bg" \
  --input_woman_no_bg "/path/to/masked_images/woman_no_bg" \
  --output_path "/path/to/masksga_embeddings_siglip" \
  --batch_size 1
```

The default model is `google/siglip-base-patch16-224`. Image embeddings are extracted using the model's pooled visual features.

**DINOv2 with dense patch features**

```bash
python embeddings_maskSGA.py \
  --embedding_model dinov2 \
  --input_man_bg "/path/to/masked_images/man_bg" \
  --input_man_no_bg "/path/to/masked_images/man_no_bg" \
  --input_woman_bg "/path/to/masked_images/woman_bg" \
  --input_woman_no_bg "/path/to/masked_images/woman_no_bg" \
  --output_path "/path/to/masksga_embeddings_dinov2" \
  --batch_size 1
```

The default model is `facebook/dinov2-with-registers-large`. The CLS token and register tokens are excluded, and the remaining patch-token features are averaged to produce one global descriptor per image. This is a dense-feature-based representation, rather than an embedding taken from the CLS token.

For all models, `--model_name` can be used to select another compatible model. The `--pretrained` option specifies OpenCLIP pretrained weights.

***Batch size and batch-dependent artifacts***

The batch size must be set to `1` for all embedding extraction runs. In preliminary experiments, processing multiple images together introduced batch-dependent artifacts into the extracted representations, particularly for highly pixelated images in the PixelSGA pipeline. To maintain consistency with the project's experimental setup, use `--batch_size 1` for all MaskSGA embedding extraction runs as well.

The script saves four NumPy embedding files directly in the specified output directory:

```text
masksga_embeddings_clip/
├── bg_male.npy
├── no_bg_male.npy
├── bg_female.npy
└── no_bg_female.npy
```

Use a separate output directory for each embedding model and case to avoid overwriting previous results.

### 3. Run k-NN classification

**Script:** `knn_classification_masksga.py`

Run the balanced leave-one-out k-NN classifier on the extracted embeddings:

```bash
python knn_classification_masksga.py \
  --embeddings_dir "/path/to/masksga_embeddings_clip" \
  --output_json "/path/to/masksga_results_clip.json" \
  --k 5
```

The script evaluates the embeddings separately for the `bg` and `no_bg` conditions and saves the balanced accuracy results to a JSON file. The `--k` argument specifies the number of nearest neighbors. The default value is `5`.

The classifier balances the reference set for each held-out sample by randomly downsampling the larger gender class. The results can therefore depend on the random seed; use the same random-state configuration when reproducing an experiment.

### 4. Compute MaskSGA

**Script:** `maskSGA_computation.py`

Compute the final MaskSGA score from the JSON file produced in Step 3:

```bash
python maskSGA_computation.py \
  --json_path "/path/to/masksga_results_clip.json"
```

MaskSGA is defined as the arithmetic mean of the balanced accuracies from the two masking conditions.

## Outputs

The pipeline produces:

- **Masked images:** Image collections for the `bg` and `no_bg` conditions, separately for male and female inputs.
- **Embeddings:** NumPy (`.npy`) files containing image representations for each gender and masking condition.
- **Evaluation results:** A JSON file containing balanced accuracy values for `bg` and `no_bg`.
- **MaskSGA score:** A single scalar computed as the average of the two balanced accuracies.

Each case and embedding model should have its own output paths to avoid overwriting results from previous runs.
